# UI 一致性规范（三端共用一个视觉真源）

> 真源：`shared/design/tokens.json`。Android / iOS / Harmony 各自把 token 转译为本平台主题，
> **数值必须一致**，只允许平台惯用的控件外观差异（如返回手势、系统字体字重微调）。
> 三端的页面结构、信息层级、间距节奏、配色、交互反馈保持 1:1。

## 1. 全局

- 背景 `background #F4F6FB`，内容卡片 `surface #FFFFFF`，圆角 `radius.lg=18`，
  卡片内边距 `spacing.lg=16`，页面左右 `pagePadding=16`；卡片使用 1px 柔和描边 + 轻阴影。
- 顶部主视觉使用渐变 Hero（`gradient.hero`），带半透明装饰光斑；禁止大面积纯色平涂。
- 快捷入口/功能图标使用 `iconPalette` 的 8 组柔和底色 + 主题色，形成有层次的彩色图标块。
- 主色 `primary #1F5F99` 用于导航栏、主按钮、选中态、进度条；
  深色 `primaryDark #16466F` 用于沉浸式导航栏；主按钮使用 `gradient.primary`。
- 辅助色：`accent #2FA6A0`、`violet #7C5CFC`、`amber #F59E0B`、`coral #E56B6F`，
  仅用于图标块、统计块、状态提示，不替代主色。
- 文本：主 `#1F2937`，次 `#8A94A6`，弱 `#94A3B8`。
- 正文 `body=15`，次要 `small=13`，标题 `title=17`，页面主标题 `headline=20`。
- 所有页面统一安全区内边距；底部固定操作栏高 `bottomActionHeight=64`。

## 2. 导航

- 底部 Tab 四项固定：**首页 / 考试 / 练习 / 我的**，未选中 `#8A94A6`，选中 `#1F5F99`。
- Android：`NavigationBar`；iOS：`TabView`；Harmony：`Tabs`（底部）。
- 二级页面统一左返回 + 居中标题；考试作答页右侧显示倒计时。

## 4. 关键页面结构（三端一致）

### 首页
渐变 Hero（日期/平台标签/问候语/两个主行动）→ 快捷服务 4×2 彩色图标网格 → 考试报名入口
→ 首页组件：BANNER 图片轮播（渐变遮罩 + 文案）、NAV 彩色入口、NOTICE 公告条、
HOT_EXAM 横向卡片、ARTICLE / TEACHER / CLASS_RECOMMEND 带「查看更多」的列表 → 空态。

### 考试列表
渐变问候 Hero → 搜索框 + 付费筛选（全部/免费/付费）+ 排序（最新/名称/价格升降）
→ 我的考试卡片（封面、标题、试卷名/价格、简介、时间/时长/总分/得分、状态徽标、开始/看成绩）
→ 开放考试（准入方式、价格、资格徽标、缴费/开始/去报名）→ 密码弹窗 → 空态。

### 作答页
顶部：题号 `i/N`、已答、当前题分值、倒计时、保存状态。
中部：题号 + 题型徽标 + 标记按钮 → 题干（富文本）→ 选项/填空/问答输入。
底部固定：上一题 / 答题卡 / 下一题（末题变「交卷」）。
答题卡：5 列题号网格 + 图例 + 交卷按钮。

### 成绩页
总分大数字 + 是否通过徽标 → 客观/主观得分 → 对错与待阅统计 → 返回首页/查看解析。

### 个人中心
渐变 Hero（头像 + 姓名/账号 + 学员徽标）→ 分组列表「学习与成绩 / 练习与成长 / 账号与安全」
（彩色图标块 + 箭头）→ 柔和危险色「退出登录」。

### 练习
渐变 Hero → 练习概览统计块 → 题库卡片（模式/题量/限时/积分/价格/锁定状态）
→ 密码弹窗；购买类锁定跳转会员中心并携带待支付业务；作答支持选择/多选/判断/多空填空/问答，
逐题判定并展示正确答案与解析，完成时弹窗确认结束。

### 登录 / 注册
顶部渐变头（Logo + 标题 + 副标题）→ 白色悬浮卡片表单 → 渐变主按钮 → 辅助链接。
短信登录/注册/重置密码与租户选择保持同样结构。

## 5. 状态与反馈

- 所有网络请求：加载中、成功、失败三态；失败统一轻提示（Toast/SnackBar）显示服务端 `message`。
- 401 一律清会话并跳登录。
- 作答保存状态用 `pending/saving/saved/error` 文案与颜色区分，error 用 danger。
- 交卷/退出等破坏性操作用确认对话框。
