# UI 一致性规范（三端共用一个视觉真源）

> 真源：`shared/design/tokens.json`。Android / iOS / Harmony 各自把 token 转译为本平台主题，
> **数值必须一致**，只允许平台惯用的控件外观差异（如返回手势、系统字体字重微调）。
> 三端的页面结构、信息层级、间距节奏、配色、交互反馈保持 1:1。

## 1. 全局

- 背景 `background #F4F6FB`，内容卡片 `surface #FFFFFF`，圆角 `radius.lg=16`，
  卡片内边距 `spacing.lg=16`，页面左右 `pagePadding=16`。
- 主色 `primary #1F5F99` 用于导航栏、主按钮、选中态、进度条；
  深色 `primaryDark #16466F` 用于沉浸式导航栏。
- 文本：主 `#1F2937`，次 `#8A94A6`，弱 `#94A3B8`。
- 正文 `body=15`，次要 `small=13`，标题 `title=17`，页面主标题 `headline=20`。
- 所有页面统一安全区内边距；底部固定操作栏高 `bottomActionHeight=64`。

## 2. 导航

- 底部 Tab 四项固定：**首页 / 考试 / 练习 / 我的**，未选中 `#8A94A6`，选中 `#1F5F99`。
- Android：`NavigationBar`；iOS：`TabView`；Harmony：`Tabs`（底部）。
- 二级页面统一左返回 + 居中标题；考试作答页右侧显示倒计时。

## 3. 组件（三端同名同构）

| 组件 | 规范 |
|------|------|
| `PageScaffold` | 背景色 + 安全区 + 可选标题栏 + 内容滚动 |
| `SectionCard` | 白底、圆角 16、内边距 16、轻阴影 |
| `ListRow` | 高 56、左主文案右箭头、底部分隔线 `border` |
| `PrimaryButton` | 主色填充、圆角 pill、高 48、白字 16 |
| `SecondaryButton` | 主色描边、透明底、主色字 |
| `TagPill` | 11 号字、圆角 pill、按题型/状态取色 |
| `EmptyState` | 居中图标 + 灰字「暂无数据」 |
| `LoadingState` | 居中转圈 |
| `ErrorBanner` | dangerSoft 背景 + danger 文案 |
| `StatusBar` | 作答页顶部：题号进度 / 已答 / 分值，背景 primarySoft |
| `AnswerSheet` | 5 列网格，已答=primarySoft 底，当前=主色描边，标记=warning 描边 |
| `OptionRow` | 圆形字母徽标 + 选项文本；选中=主色描边+浅主色底 |
| `CountdownTimer` | 等宽数字；剩余 ≤ 300s 变 danger |

## 4. 关键页面结构（三端一致）

### 首页
问候语 → 快捷入口 4×2 网格 → 首页组件（BANNER 轮播 / NAV / 列表区块）→ 空态。

### 考试列表
筛选 Tab（全部/进行中/已结束）→ 考试卡片：标题、试卷名、时间、时长、状态徽标、分数。
卡片点击：未开始提示，进行中进入作答，已交卷进入成绩。

### 作答页
顶部：题号 `i/N`、已答、当前题分值、倒计时、保存状态。
中部：题号 + 题型徽标 + 标记按钮 → 题干（富文本）→ 选项/填空/问答输入。
底部固定：上一题 / 答题卡 / 下一题（末题变「交卷」）。
答题卡：5 列题号网格 + 图例 + 交卷按钮。

### 成绩页
总分大数字 + 是否通过徽标 → 客观/主观得分 → 对错与待阅统计 → 返回首页/查看解析。

### 个人中心
头像+用户名 → 功能分组列表（成绩/申诉/日历/通知/练习/错题/考试组/会员/分析/设备）→ 修改密码 → 退出登录。

## 5. 状态与反馈

- 所有网络请求：加载中、成功、失败三态；失败统一轻提示（Toast/SnackBar）显示服务端 `message`。
- 401 一律清会话并跳登录。
- 作答保存状态用 `pending/saving/saved/error` 文案与颜色区分，error 用 danger。
- 交卷/退出等破坏性操作用确认对话框。
